# Доступ к чату с других устройств

Python-сервер запускается на одном компьютере. На телефоне и других клиентских устройствах нужен только браузер. Все пользователи должны открывать адрес одного и того же сервера.

## Локальная сеть

1. Подготовьте проект через `setup.bat`.
2. Запустите `start_network.bat`.
3. Откройте «Ссылка на чат» и выберите сетевой адрес серверного компьютера вида `http://192.168.1.10:8000`.
4. Откройте этот адрес на втором устройстве из той же сети.

Адрес в примере условный; используйте значение, показанное вашим сервером. Если Windows предлагает разрешить входящие подключения, разрешите их для используемой доверенной сети. Адрес `127.0.0.1` указывает на само устройство и не подходит для подключения к другому компьютеру.

## Разные сети

1. Выполните `setup_internet.bat`. Он скачивает официальную утилиту Cloudflare Tunnel фиксированной версии и проверяет её SHA-256.
2. Запустите `start_internet.bat`.
3. Дождитесь готовности туннеля и откройте «Ссылка на чат».
4. Скопируйте показанный HTTPS-адрес и откройте его на клиентском устройстве.

Это временная ссылка Cloudflare Quick Tunnel. Компьютер, сервер и туннель должны оставаться включёнными. После перезапуска ссылка может измениться. Локальный доступ при этом продолжает работать.

Ссылка на репозиторий GitHub открывает код проекта. Адрес действующего чата выдаётся запущенным сервером; это разные ссылки.

## Остановка и устранение ошибок

- для завершения работы используйте `stop.bat`;
- если порт занят, остановите предыдущий экземпляр либо задайте другой порт при ручном запуске;
- если модель недоступна, повторите `scripts/download_model.py` в виртуальном окружении и перезапустите сервер;
- если внешний адрес не появился, проверьте соединение с интернетом и журналы в локальном каталоге данных;
- не запускайте два сервера с одной базой одновременно.
