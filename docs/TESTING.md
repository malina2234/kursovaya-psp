# Проверка программы

## Автоматические проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проверяются валидация текста, разбор TXT/CSV/JSON, авторизация, личные диалоги, ограничения доступа, административные действия, классификация пользователей, статистика файлов и календарные выборки.

Тесты используют временные базы и управляемую тестовую модель. Они проверяют логику приложения и не измеряют точность нейросети на независимом корпусе.

Календарные расчёты клиентских графиков проверяются при наличии Node.js:

```powershell
node --test tests/test_charts.js
```

## Проверка с настоящей моделью

Подготовьте зависимости и модель, затем запустите отдельный экземпляр:

```powershell
.\.venv\Scripts\python.exe main.py --no-browser --data-dir test_data --port 8001
```

В другом терминале выполните:

```powershell
.\.venv\Scripts\python.exe scripts/smoke_test.py --base-url http://127.0.0.1:8001
```

Сценарий создаёт тестовые аккаунты и сообщения, проверяет реальное применение модели, обмен между клиентами и обработку файлов. Для него используйте отдельный каталог данных. Созданный протокол хранится локально и не включается в репозиторий.

## Ручная демонстрация

После установки запустите `demo.bat`. В отдельной демонстрационной базе будут созданы три аккаунта с паролем `demo2026`. Для проверки загрузки и статистики используйте файлы из `samples/`.

Демонстрационные наборы содержат повторяющиеся фразы. Совпадение ожидаемых меток с ответом модели на них не является оценкой качества на независимой выборке.
