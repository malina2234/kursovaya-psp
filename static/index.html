Удалить участника?

Участник исчезнет из списка, все его сеансы завершатся. Войти в удалённый аккаунт или зарегистрироваться с тем же именем будет нельзя.

Старые сообщения сохранятся с пометкой «удалён». Личные диалоги с этим участником останутся доступны только для просмотра.

Скачать переписку

Сохранится вся переписка выбранного чата, включая ранние сообщения и оценки тональности.

Очистить общий чат?

Все сообщения общего чата будут удалены у всех участников. Восстановить их через приложение будет нельзя.

Личные диалоги, аккаунты и результаты обработки файлов сохранятся. Статистика пересчитается по оставшимся сообщениям.
